# 截图目录

请将以下截图放入本目录，文件名必须一致（README.md 中引用了这些路径）：

| 文件名 | 内容说明 | 建议截取方式 |
|---|---|---|
| `home.png` | 首页：教材/年级/学期选择 + 本轮成绩卡片 | 做完一轮题后回首页截（含成绩卡片更完整） |
| `game.png` | 游戏页：字谜题目 + 单字输入框 + 提示按钮 + 赞踩按钮 | 出题后截，最好已点过一次提示 |
| `submit.png` | 上传字谜表单页 | 直接访问 /submit 截 |
| `admin-login.png` | 管理后台密码登录页 | 直接访问 /admin 截（未登录状态） |

## 截图建议

- 桌面端宽度 1280px 左右，或手机宽度 390px（展示移动端适配）
- 游戏页建议截一张答对后的状态（含汉字详情卡片 + 撒花动画）
- 可额外补充：`share-image.png`（分享成绩弹窗）、`admin-panel.png`（登录后的审核列表）

补充截图后记得在根目录 README.md 的截图表格中添加对应行。
